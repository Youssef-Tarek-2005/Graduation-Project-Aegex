Realistic benchmark, test only. Detection = share of attacker/target host-snapshots flagged; false alarms = share of other host-snapshots flagged. Baseline = the host has any LSTM-AE or VAE alert in that minute.

Known vs never-seen attack types

Each "unseen" column comes from a GAT retrained with that whole attack type removed from training. This is the zero-day question for stage 3.

Control injections

Normal traffic injected exactly like an attack. The "injected" host did nothing wrong, so a good detector flags it about as rarely as any normal host.
