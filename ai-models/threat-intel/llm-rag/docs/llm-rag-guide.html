02 · أهم اكتشاف

الـ index مبني ومرفوع في الريبو

أول حاجة عملتها إني فتحت ملف indices/faiss_index/manifest.json. ولقيت ده:

{
  "corpus_version": "1.0.0",
  "vectorstore_backend": "faiss",
  "embedding_model": "nomic-embed-text",
  "embedding_provider": "ollama",     // ← المهم
  "document_count": 3306,
  "chunk_count": 3312,
  "built_at": "2026-06-10T13:27:29Z"
}

الـ embedding_provider هو ollama. يعني صاحب الريبو بنى الـ index بنفس الطريقة اللي إحنا هنشغّل بيها محليًا. النتيجة:

✓ اللي مش محتاج تعمله
  • ❌ مش محتاج تحمّل MITRE ATT&CK (ملف ~40 ميجا)
  • ❌ مش محتاج تدخل على cisa.gov (واللي ممكن يتحجب عليك زي Kaggle)
  • ❌ مش محتاج تشغّل ingest.py ولا تستنى بناء الـ embeddings
  • ❌ مش محتاج HuggingFace خالص على البروفايل المحلي
  • ❌ مش محتاج Groq API key

تأكدت إن الـ index سليم فعلًا: حمّلته بنفسي، طلع 3,312 vector بـ 768 بُعد، وكل مستند جوّاه الـ metadata بتاعته كاملة — العنوان، النوع، الـ ID، والـ url اللي بيستخدمه في الـ citations.

نصّب Ollama

Ollama هو اللي هيشغّل الموديل على جهازك. مفتوح المصدر ومجاني ومفيش فيه حسابات ولا مفاتيح.

1

2
شغّل الأمر دهwinget هيحمّل وينصّب لوحده
winget install --source winget --id Ollama.Ollama
💡 لاحظ --source winget

نفس المشكلة اللي قابلتنا مع Python. من غيرها winget بيحاول يجيبها من msstore وبيطلّع error في الشهادة. الـ flag دي بتجبره على المصدر الصح.

لو winget مرضيش، حمّل الـ installer من الموقع الرسمي: https://ollama.com/download/windows

اقفل الـ PowerShell وافتح واحد جديد

ضروري — عشان الـ PATH يتحدّث. وبعدين اتأكد:

ollama --version
✓ المتوقع

05 · الخطوة 2

حمّل الموديلين

موديلين، كل واحد له دور مختلف تمامًا:

الموديلالحجمدوره
nomic-embed-text~274 ميجايحوّل سؤالك لـ 768 رقم عشان البحث في الـ index
gemma3:4b~3.3 جيجايكتب الإجابة النهائية من المستندات
ollama pull nomic-embed-text
ollama pull gemma3:4b
🔍 ليه الموديلين دول بالتحديد؟

مش اختيار عشوائي. الـ manifest.json قال إن الـ index اتبنى بـ nomic-embed-text — فلازم نستخدم نفسه في البحث. والـ gemma3:4b هو اللي الريبو موصّي بيه ومجرَّب عليه.

💡 الـ RTX 3050 بتاعتك

gemma3:4b بعد الـ quantization حواليه 3.3 جيجا، فهيدخل في الـ 4 جيجا VRAM بتاعتك تقريبًا كله. Ollama بيوزّع لوحده بين الـ GPU والرام — مش محتاج تضبط حاجة. متوقع 15-30 توكن/ثانية، سريع كفاية للعرض الحيّ.

تشيك

ollama list

لازم تشوف السطرين. لو ناقص واحد، اعمل له pull تاني.

⚠ لو ظهر error في الـ Execution Policy

-Scope Process معناها إن التغيير للنافذة دي بس وبيختفي لما تقفلها — أأمن من إنك تغيّر إعدادات الجهاز كله.

08 · الخطوة 5

ملف الإعدادات .env

الريبو افتراضيًا مظبوط على البروفايل السحابي (Groq + HuggingFace). إحنا عايزين المحلي. متنسخش .env.example زي ما هو — هنكتب الملف من الأول.

اعمل ملف اسمه .env في نفس فولدر الريبو، وحطّ فيه ده بالظبط:

DEPLOYMENT_PROFILE=local
LLM_PROVIDER=ollama
LLM_MODEL=gemma3:4b
OLLAMA_BASE_URL=http://localhost:11434

EMBEDDING_PROVIDER=ollama
EMBEDDING_MODEL=nomic-embed-text

VECTORSTORE_BACKEND=faiss
RETRIEVAL_TOP_K=5
CONFIDENCE_THRESHOLD=40
HARD_ABSTENTION_ENABLED=true
RETRIEVAL_ONLY_FALLBACK=true
LLM_REWRITE_FOLLOWUPS=true
INCLUDE_GROUPS_SOFTWARE=true
MEMORY_MAX_TURNS=3
INGEST_BATCH_SIZE=32

DATA_RAW_DIR=data/raw
DATA_PROCESSED_DIR=data/processed
INDICES_DIR=indices/faiss_index
✓ الملف ده متحقَّق منه

كتبته وشغّلته على كود الريبو نفسه (config/settings.py) وقبله من غير أي error في الـ validation. مش مجرد تخمين.

أسهل طريقة تعمله من PowerShell — افتحه في Notepad والصق:

notepad .env

Notepad هيسأل "تعمل الملف؟" — قول آه، الصق، واعمل Save.

09 · فهم الإعدادات

إيه اللي ضبطناه ولِيه

أربع إعدادات من دول هي قلب موضوع منع الهلوسة — وده أهم حاجة تعرفها عن الطبقة دي في المناقشة.

الإعدادمعناه
RETRIEVAL_TOP_K=5يجيب أقرب 5 مستندات بس. أكتر = ضوضاء، أقل = معلومات ناقصة
CONFIDENCE_THRESHOLD=40لو الثقة أقل من 40%، النظام يرفض يجاوب بدل إنه يألّف
HARD_ABSTENTION_ENABLED=trueالامتناع إجباري، مش اقتراح للموديل
RETRIEVAL_ONLY_FALLBACK=trueلو الموديل وقع، يعرض المستندات اللي لقاها على الأقل

الـ prompt اللي بيفرض ده

قريت src/rag/prompts.py. فيه تعليمات صريحة للموديل:

  • كل جملة لازم يكون جنبها citation بالشكل [T1059.001] أو [G0007] أو [CVE-2024-1234]
  • ممنوع يختلق أي ID مش موجود في المستندات
  • لو مش لاقي دليل، يقول نص محدَّد بالحرف: "I don't have enough grounded evidence to answer confidently."
🎯 الجملة اللي تقولها للدكتور

"الطبقة دي مربوطة بمصادر (grounded). مش LLM بيتكلم من دماغه — كل جملة لها citation من MITRE أو CISA، ولو مفيش دليل كافي النظام بيمتنع عن الإجابة بدل إنه يهلوس. وده متحقَّق منه في الـ prompt وفي عتبة الثقة."

11 · فخ لازم تعرفه

متغيّرش مصدر الـ embeddings

ده أخطر حاجة في الريبو ده، ومفيش فيه أي تحذير منها، فخد بالك.

⚠ المشكلة

الـ index اتبنى بـ Ollama nomic-embed-text. لو شغّلت البروفايل السحابي (EMBEDDING_PROVIDER=huggingface) مع نفس الـ index، مش هيطلع error — الاتنين 768 بُعد فالأبعاد متوافقة. بس البحث هيبوظ بالهدوء وهيجيب مستندات غلط، وانت مش هتعرف ليه.

القاعدة

لو استخدمتلازم
الـ index الجاهز اللي في الريبوEMBEDDING_PROVIDER=ollama — زي ما ظبطناه

🔍 لو الدكتور سأل

السؤال المتوقع: "إزاي عرفت إن الـ index متوافق؟" الرد: "من manifest.json — بيسجّل الـ embedding provider والموديل اللي اتبنى بيهم، وأنا تأكدت إن إعدادات التشغيل مطابقة ليهم." ده يوري إنك فاهم النظام، مش بس مشغّله.

12 · اختياري

لو عايز تبني الـ index بنفسك

مش محتاج ده للعرض — الـ index الجاهز كفاية. بس لو عايز تقول في المناقشة إنك بنيت القاعدة بنفسك، أو عايز تحدّثها:

python scripts/ingest.py --validate-only

يتحقق من البيانات بس. وبعدين:

python scripts/ingest.py --build-index

إيه اللي بيحصل

  1. بيحمّل enterprise-attack.json من raw.githubusercontent.com (~40 ميجا)
  2. بيحمّل known_exploited_vulnerabilities.csv من cisa.gov
  3. بيقسّمهم chunks ويعمل embedding لكل واحد بـ Ollama
  4. بيكتب index جديد في indices/faiss_index
⚠ لو cisa.gov محجوب عليك

احتمال كبير — زي ما حصل مع Kaggle. الحل: حمّل الملفين من تليفونك أو أي نت تاني، وحطّهم يدويًا في data/raw/ بنفس الأسماء بالحرف:

  • enterprise-attack.json
  • known_exploited_vulnerabilities.csv

السكربت بيشيك لو الملف موجود، ولو موجود بيستخدمه ومش بيحاول يحمّل.

وممكن تجرّب سؤال في نفس الأمر:

python scripts/ingest.py --build-index --test-query "How is T1059 used?"

15 · الختام

تشيك ليست وخطوة جاية

  • ollama --version بيطبع رقم
  • ollama list فيه nomic-embed-text و gemma3:4b
  • الريبو منزّل و (.venv) مفعّل
  • pip install -r requirements.txt خلص من غير error
  • ملف .env موجود وفيه DEPLOYMENT_PROFILE=local
  • streamlit run app.py فتح الصفحة
  • سؤال T1059 رجع إجابة فيها citations
  • سؤال خارج النطاق رجع امتناع (ده نجاح!)

ليه مش محتاجين نشغّل ingest.py؟

الـ manifest.json بيقول إن الـ index اتبنى بـ Ollama nomic-embed-text — نفس اللي إحنا هنشغّله. فالـ 3,312 chunk جاهزين ومتوافقين. ده وفّر علينا تحميل 40 ميجا، دخول على cisa.gov المحتمل يتحجب، ووقت بناء الـ embeddings.

لو النظام رفض يجاوب على سؤال، ده إيه؟

دي ميزة مقصودة. CONFIDENCE_THRESHOLD=40 + HARD_ABSTENTION_ENABLED=true بيخلّوا النظام يقول "مش عندي دليل كافي" بدل إنه يألّف إجابة. في مجال الأمن، إجابة مألّفة أخطر من مفيش إجابة.
